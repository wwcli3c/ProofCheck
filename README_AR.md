# ProofCheck 1.1 — نظام فحص الأجهزة وتوثيق الإصلاحات

**ابدأ بقراءة [START_HERE_AR.md](START_HERE_AR.md)** لنشر التطبيق كرابط إنترنت عام على Render أو VPS، أو تشغيل نسخة الكمبيوتر المحلية.

تم تطوير هذا الإصدار انطلاقًا من مشروع ProofCheck المحلي السابق. يدعم جلسة منفصلة برمز خاص لكل زائر، وموافقة على التخزين قبل إنشاء الجلسة، ومعلومات الجهاز المتاحة في المتصفح، واختبارات شاشة ولمس وكاميرا وميكروفون وسماعات ولوحة مفاتيح، وقياسات قصيرة على **متصفح الزائر** للمعالج والذاكرة وIndexedDB، وسجل إصلاحات، وإرفاق صور/PDF، وتقارير قابلة للطباعة/الحفظ، وروابط عرض محدودة الصلاحية.

في نمط `desktop` يمكن للنسخة التي تعمل على الكمبيوتر المحلي الاستعلام من نظام التشغيل وإجراء قياسات محلية إضافية. هذه المعلومات **لا تنتقل** إلى جهاز الزائر عند تشغيل نسخة `web`؛ ولن يدّعي الموقع أنه عرف قطع الأجهزة الأخرى عن بُعد.

**الصدق في النتيجة:** النتائج مقسمة حسب مصدرها (قياس محلي/قياس متصفح/إفادة نظام/اختبار يؤكده المستخدم/غير متاح). علامة «اجتاز» تعني اكتمال الاختبار الموصوف فحسب، وليست شهادة بأصالة القطعة أو خلو الجهاز من العيوب أو عدم استبدال أي قطعة.

## التشغيل للاختبار المحلي

Python 3.10+، من جذر المجلد:

```bash
python server.py --mode web --port 8765 --no-browser
```

افتح `http://127.0.0.1:8765` **على الجهاز نفسه**. لن يصبح الرابط عامًا بمجرد تشغيل هذا الأمر. لتشغيل فحص عتاد الكمبيوتر محليًا شغّل `start_windows.bat` أو `sh start_mac_linux.sh` بدلًا من أمر وضع الويب.

## اختبار الكود

```bash
python -m unittest discover -s tests -v
```

تتحقق الاختبارات من API والجلسات والعزل بينها والحفظ والحذف ورفع الملفات وروابط المشاركة والحجب، مع قواعد وضع الويب والفحوصات المحلية القصيرة. بيئة إنتاج عامة أو متصفحات وأجهزة فعلية **لم تُختبر من خلال هذه الحزمة**، ويلزم التحقق بعد النشر.

## الحماية والخصوصية

الخادم يقدم التطبيق من مصدر واحد ويمنع الطلبات من أصول أخرى، ولا يفتح واجهة قراءة عتاد الخادم في وضع الويب. يخزن بيانات الزوار على خادمك ضمن SQLite، ولا يرسلها تلقائيًا إلى أطراف أخرى. تنتهي روابط التقارير تلقائيًا بعد 1–30 يومًا، ويمكن إلغاؤها، ويحجب التقرير العام بيانات حساسة مختارة؛ لكن ملاحظات المستخدم قد تتضمن تفاصيل اختار مشاركتها بنفسه. يجب نشر سياسة خصوصية واتفاقية استخدام مناسبة قبل طرح المنتج تجاريًا.

تحتوي الحزمة على نماذج تشغيل Render وDocker Compose/Caddy وملف نسخ احتياطي آمن من SQLite. رموز الجلسات مفاتيح وصول سرية؛ لا تستخدمها ضمن روابط عامة أو تشاركها في الرسائل أو المستودعات.
