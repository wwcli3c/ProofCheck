# ProofCheck 1.1 — الوظائف حسب طريقة الدخول

| الميزة | من رابط HTTPS عام على الجوال أو الكمبيوتر | برنامج محلي على Windows/macOS/Linux |
|---|---|---|
| شاشة، لمس، كاميرا، ميكروفون، سماعات | نعم حسب المتصفح والتصاريح | نعم حسب المتصفح والتصاريح |
| اختبار لوحة المفاتيح / الاهتزاز عند الدعم | نعم حسب المتصفح | نعم حسب المتصفح |
| سرعة الحسابات في JavaScript | نعم، قياس محدود في متصفح الزائر | قياس Python على الكمبيوتر |
| قراءة/كتابة 8MiB في ذاكرة المتصفح | نعم، ليس اختبار سلامة RAM | قياس صغير على ذاكرة الكمبيوتر |
| فحص تخزين IndexedDB 2MiB | نعم، لا يقيس سرعة/صحة SSD مباشرة | قياس ملف محلي مؤقت 64MiB |
| قراءة طراز المعالج وأجزاء RAM من نظام التشغيل | لا؛ البيانات محدودة بما يكشفه المتصفح | قد تتوفر بحسب OS والتصاريح |
| صحة البطارية والتخزين SMART | في الغالب غير متاحة للمتصفح | عند كشفها من OS/smartctl فقط |
| إثبات الأصالة أو استبدال القطع بصورة قطعية | **غير ممكن بصورة شاملة** | **غير ممكن بصورة شاملة** |
| حفظ جلسات متعددة واستعادتها برمز خاص | نعم بعد موافقة حفظ البيانات | نعم |
| سجل إصلاحات ومرفقات PNG/JPEG/WebP/PDF | نعم | نعم |
| طباعة PDF وJSON وروابط تقارير قراءة فقط | نعم بعد استضافة HTTPS | نعم؛ روابط التقارير العامة تتطلب استضافة |
| PWA على شاشة الهاتف | على HTTPS عند دعم المتصفح | على localhost أو HTTPS عند الدعم |

الاختبارات البرمجية لا تعادل اختبارات اعتماد ميدانية على أجهزة حقيقية. استضافة الموقع وصلاحيات الجهاز قد تؤثر في توفر الوظائف.
